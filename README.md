# PixShot —— 截图 / 贴图 / OCR

仿 Snipaste 的 Windows 桌面小工具：常驻托盘，一键截图，贴图钉在桌面，框选即可识别文字。
纯 Rust 实现，OCR 由本地模型离线推理，开箱即用、无需联网。

## 功能

| 功能 | 说明 |
|------|------|
| **托盘常驻** | 启动后只驻留任务栏托盘，不弹窗。全局热键（默认 **F1**，可配置）或左键点击托盘图标开始截图；右键菜单含「截取全屏」「开机启动」与「退出」 |
| **截图** | 热键后整屏冻结（暗化周边 + 提亮选区 + 实时显示「宽 × 高」），十字光标拖动框选并叠加红色框线，Esc 取消。松手后冻结画面与红框保留，直到点工具栏按钮才一起消失。只做区域截图 |
| **智能选区** | 默认 `region`：不拖动、单击即自动扩充为光标下窗口；`R/W/E` 切换区域/窗口/UI 元素级，悬停预览候选框（`Tab` 父/子、`Enter` 提交）。UIA 不可用时自动退化为窗口级 |
| **截图辅助** | 选区阶段显示放大镜（`Ctrl+滚轮` 调倍率）、四向辅助线与九宫格、坐标/尺寸/颜色信息条；`C` 复制当前像素颜色（`Shift+C` 循环 Hex/RGBA/RGB/HSL/HSV 格式） |
| **工具栏** | 选区底部的紧凑白色圆角卡片，纯图标按钮：**贴图 / 保存 / 复制并关闭 / 复制识别到的文字 ｜ 矩形 / 箭头 / 步骤序号 / 颜色面板 / 更多（…）/ 关闭**；功能组（前 4 个）与标注组之间以竖杠分隔，悬停出提示气泡（含快捷键）。悬停「…」弹出带小尖角的子工具条（**椭圆 / 线段 / 马赛克 / 画笔 / 文字 / 高亮 / 橡皮 / 水印**），光标离开后自动收起。点任一导出按钮后自动关闭 |
| **标注** | 选区确认后可继续在冻结画面上标注：**矩形 / 箭头 / 步骤序号 / 椭圆 / 线段 / 画笔 / 马赛克 / 高亮 / 文字 / 水印**。可选中移动、拖控制柄缩放、Delete 删除，Ctrl+Z / Ctrl+Y 撤销重做；贴图/保存/复制/OCR 动作会先把标注合成进成品 |
| **颜色面板 / 橡皮** | 颜色面板显示在工具条下方并与工具条右侧对齐，**只提供 8 个预设颜色块：红 / 绿 / 蓝 / 青 / 品红 / 黄 / 黑 / 白（顺序固定）**（改选中对象颜色或后续默认色），选中颜色后自动收起，也可再次点击工具条颜色按钮或 `Esc` 关闭；对象橡皮拖过即删，整次拖动一条撤销；`Ctrl+Shift+Delete` 清空全部（一条撤销） |
| **Ctrl+滚轮调标注尺寸** | 选中标注工具后，光标在画布任意位置按住 `Ctrl` 滚动滚轮即可调整：矩形/箭头/椭圆/线段/画笔调**线宽**，文字/水印调**字号**，步骤序号调**半径**，橡皮调**容差**；每步调整都用 Toast 实时显示当前值 |
| **文字水印** | 文字水印参与合成导出，支持角度/透明度/平铺与间距配置 |
| **打码 / 高亮** | 马赛克支持**块平均**或**模糊**两种模式；高亮支持**荧光笔色块**或**聚光灯**（整图压暗、圈出亮区）。模式在配置文件中切换 |
| **画笔** | 自由绘制，支持**硬笔 / 软笔**（按笔速渐细）**/ 渐隐笔**（彗尾）；画笔形态在配置文件中切换 |
| **文字与挂线** | 文字可加粗 / 斜体，可选**气泡**或**爆炸云**外框；落点靠近线段/箭头时自动**挂线**，随线段一起移动 |
| **贴图** | 截图以无边框置顶小窗钉在桌面，四周带柔和投影。左键拖动、边缘拖动缩放、滚轮以光标为锚点缩放、`Ctrl+滚轮` 调整透明度（最低 10%）；右键菜单（复制 / 保存 / 识别文字 / 重置缩放 / 锁定 / 置顶 / 阴影 / 关闭），双击或 Esc 关闭 |
| **OCR** | 内置本地 ONNX 推理链（PP-OCRv4 中英模型，检测 + 识别 + 按行重建），离线可用。工具条「复制识别到的文字」与贴图右键菜单「识别文字」行为一致：后台识别 → 文字写入剪贴板 → 右下角提示，**都不弹出结果窗口**。缺模型或运行时时自动回退系统 `Windows.Media.Ocr` |
| **截取全屏** | 托盘右键「截取全屏」：静默抓整屏 → 复制到剪贴板 → 按默认命名存盘（默认目录 `图片\PixShot`）→ 右下角提示，不进入框选 |
| **保存命名** | 默认文件名 `截图_YYYYMMDD_NN.<ext>`，按当天已有文件递增（01…99） |
| **提示** | 操作反馈用非模态 Toast（右下角自动消失），不弹系统消息框打断操作 |
| **配置** | 同目录 `config.ini` 分节纯文本配置：热键、保存格式/目录/文件名、OCR 语言/版面/标点/置信度与识别调参、标注样式（颜色/线宽/字号/容差）、界面尺寸与配色、贴图、文本/富文本贴图等 |

支持保存为 **PNG / JPEG / BMP**，或复制为位图到剪贴板。

## 构建与运行

要求 Windows 10 1809+ / Windows 11，以及 [Rust](https://rustup.rs/)
（`x86_64-pc-windows-msvc` 或 `x86_64-pc-windows-gnu` 均可）。

```powershell
cargo build --release          # 发布构建
cargo run --release            # 运行（常驻托盘，按 F1 或点托盘图标截图）
cargo run --release -- --smoke # 无界面冒烟测试：全屏截图 → 保存 → OCR
cargo test                     # 单元 + 集成测试
pwsh -File scripts\ci.ps1      # 本地 CI（check → test → build → E2E）
```

发布产物是 `target\release\` 整个目录，拷走即可运行：

| 文件 | 约 | 说明 |
|---|---|---|
| `pixshot.exe` | 3.1 MB | 主程序 |
| `onnxruntime.dll` | 15 MB | OCR 推理运行时 |
| `model\det.onnx`、`model\rec.onnx` | 16 MB | OCR 检测 / 识别模型 |

运行时与模型由构建脚本自动摆到 exe 同目录；**缺失时程序仍可用**，OCR 自动回退系统引擎。
不需要嵌入应用图标时可跳过：`PIXSHOT_NO_ICON=1 cargo build`。

## 配置文件

首次启动会在 `pixshot.exe` 同目录生成带注释的 `config.ini`（UTF-8）。
**修改后重启生效**，删除该文件即恢复默认。

配置文件按用途分节（`[section]`），节名仅用于组织，键名在全文件内唯一。
所有可调参数都在这里：热键 / 保存 / OCR / 标注样式（颜色、线宽、字号、容差）/
界面尺寸与配色 / 贴图 / 文本与富文本贴图 / 文件名等。

```ini
[hotkey]
hotkey     = F1              ; 全局热键，支持 Ctrl / Alt / Shift / Win 组合，如 Ctrl+Shift+S
pin_hotkey = F3              ; 剪贴板贴图热键

[general]
format         = png         ; 保存格式：png / jpg / bmp
save_dir =                   ; 默认保存目录，留空则用系统默认位置
toast_ms       = 1600        ; 操作提示停留毫秒数（300-10000）
capture_cursor = false       ; 截图是否包含鼠标指针：true / false

[ocr]
lang             =           ; OCR 语言，留空自动回退（仅回退到系统 OCR 时生效）
layout_type      = auto      ; 版面：auto / single / multi
punctuation_type = none      ; 标点：none / full（半角→全角）/ half（全角→半角）
remove_spaces    = 0         ; 是否删除空格（保留换行）：0 / 1
confidence       = 0.00      ; 行置信度下限 0.0-1.0
upsample_target  = 2400      ; 识别前放大目标长边（像素）
max_upscale      = 3.0       ; 放大倍数上限
dark_luma        = 110.0     ; 深底判定亮度阈值（0-255）
det_limit        = 960       ; 检测模型输入长边
det_thresh       = 0.3       ; 文本区域置信度阈值
box_thresh       = 0.6       ; 文本框分数阈值
unclip_ratio     = 1.5       ; 文本框扩张系数

[annot]
mosaic_mode    = pixelate    ; 马赛克：pixelate（块平均）/ blur（模糊）
highlight_mode = marker      ; 高亮：marker（色块）/ spotlight（聚光灯）
pen_mode       = solid       ; 画笔：solid（硬笔）/ soft（软笔）/ fade（渐隐笔）
text_bold = 0                ; 文字加粗：0 / 1
text_italic = 0              ; 文字斜体：0 / 1
text_frame = none            ; 文字外框：none / bubble（气泡）/ burst（爆炸云）
text_attach = 1              ; 文字落点自动挂线：0 / 1
stroke_color = e53935        ; 描边色（RRGGBB 或 RRGGBBAA）
stroke_width = 3             ; 线宽（逻辑像素）
text_color = e53935          ; 文字颜色
text_size = 16               ; 文字字号（逻辑像素）
badge_fill = 1e6fff          ; 步骤序号徽章底色 / 文字色 / 外圈色（空=无外圈）
badge_text = ffffff
badge_outline = ffffff
highlight_color = ffcc00     ; 荧光笔颜色
highlight_keep  = 0.55       ; 高亮混合保留系数
spotlight_dim   = 0.55       ; 聚光灯压暗系数
fade_min_alpha  = 0.12       ; 渐隐笔起点透明度
text_font = Microsoft YaHei UI
; …交互尺寸/容差/箭头/爆炸云/控制柄配色等更多项见生成的文件

[ui]                        ; 工具栏 / 提示气泡 / 选区遮罩 / Toast / 右键菜单 的尺寸与配色
toolbar_btn_size = 32        ; 依次为 按钮边长/间距/上下内边距/左右内边距/圆角
tooltip_delay_ms = 450
overlay_dim = 0.5            ; 选区遮罩暗化系数（0-1）
mica = 1                     ; 是否启用 Mica 背景

[pin]                       ; 贴图：min_scale / max_scale / shadow_margin / shadow_peak / zoom_step / fit_ratio
[textimg]                   ; 文本贴图：font_family / font_px / margin / max_width / line_spacing / fg / bg
[rtfimg]                    ; 富文本贴图：render_width / render_margin
[imageio]                   ; autosave_dir / prefix（文件名前缀）/ max_seq（序号上限）
[tray]                      ; precapture_ttl_ms（热键预捕获快照有效期）
```

非法值会自动回退默认，不会因配置写坏而启动失败。
颜色写法为 `RRGGBB` 或 `RRGGBBAA`（十六进制，可带 `#`）。

> **OCR 引擎**：优先使用同目录的 `onnxruntime.dll` + `model\{det,rec}.onnx`（离线、无需语言包）；
> 这些文件缺失时回退系统 `Windows.Media.Ocr`，此时才需要 Windows 语言包带「文字识别」可选功能。

## 操作方式

- **启动**：常驻托盘，不弹出窗口
- **触发截图**：全局热键（默认 **F1**）或左键点击托盘图标
- **框选**：拖动左键画出红色框线，松开后以框内区域为截图范围；单击或过小的拖动不产生选区，可继续框选；Esc 取消
- **工具栏**：贴图 / 保存图像 / 复制并关闭 / 复制识别到的文字 ｜ 矩形 / 箭头 / 步骤序号 / 颜色面板 / 更多（…）/ 关闭（竖杠分隔功能组与标注组）
- **更多子工具条**：悬停「…」展开 椭圆 / 线段 / 马赛克 / 画笔 / 文字 / 高亮 / 橡皮 / 水印（位于颜色面板右侧、关闭按钮左侧），光标离开自动收起
- **工具栏快捷键**：**Ctrl+T** 贴图 / **Ctrl+S** 保存 / **Ctrl+C** 复制并关闭 / **Ctrl+O** 识别文字 / **Esc** 关闭
- **标注工具**：**R** 矩形 / **A** 箭头 / **N** 步骤序号 / **E** 椭圆 / **L** 线段 / **P** 画笔 / **B** 马赛克 / **H** 高亮 / **T** 文字；选中后拖动移动、拖控制柄缩放、Delete 删除、Ctrl+Z / Ctrl+Y 撤销重做
- **调整标注尺寸**：选中标注工具后，按住 **Ctrl** 滚动滚轮即可调整线宽/字号/序号半径/橡皮容差（光标不必停在按钮上，Toast 实时显示当前值）
- **文字标注**：**T** 落点后直接键入（支持中文输入法），**Enter** 确认提交、Esc 或点击别处完成；落点靠近线段/箭头会自动挂线
- **贴图窗口**：左键拖动移动，滚轮缩放，双击左键或 Esc 关闭；右键菜单含复制图像（Ctrl+C）/ 保存（Ctrl+S）/ 识别文字（Ctrl+O）/ 重置缩放 / 关闭
- **OCR**：工具条「复制识别到的文字」与贴图右键「识别文字」结果都直接进剪贴板，右下角给出提示
- **截取全屏**：右键托盘 →「截取全屏」，静默存盘并复制到剪贴板
- **开机启动**：右键托盘 →「开机启动」切换，无需管理员权限
- **退出**：右键托盘 →「退出」

## 常见问题

程序每次启动会在 exe 同目录写诊断日志 `pixshot_diag.log`（不可写时回退 `%TEMP%`），
遇到问题先看它。一键采集：`pwsh -File scripts\diag_tray_hotkey.ps1`。

| 现象 | 解决 |
|---|---|
| 进程在运行但托盘没有图标 | Windows 11 默认把新图标收进「^」溢出区：点任务栏 `^` 找到图标并拖到托盘区固定。若由受限终端启动，改为在文件资源管理器里双击运行 |
| 按 F1 无反应 | F1 可能被其他程序占用，本版本会自动回退到键盘钩子兜底；也可在 `config.ini` 里换一个热键，或设 `PIXSHOT_FORCE_HOOK=1` 强制走钩子 |
| 双击运行也失败、托盘图标空白 | 运行目录被打了低完整性标签（常见于沙箱类工具写入的目录）。运行 `pwsh -File scripts\fix_integrity.ps1` 修复，或把 exe 复制到普通目录再运行 |
| OCR 识别不出文字 / 直接失败 | 确认 `onnxruntime.dll` 与 `model\` 与 exe 同目录；缺失时会回退系统 OCR，中文需系统语言包带「文字识别」 |
| 提示「PixShot 已启动，无需再次执行」 | 单实例保护：先在任务管理器结束所有 `pixshot.exe` 再启动 |
| 打开 exe 弹出 SmartScreen 警告 | 发布版未签名，点「更多信息 → 仍要运行」放行即可 |

## 已知限制

- 仅支持 Windows
- OCR 内置模型只带**中英**；其他语言需回退系统 `Windows.Media.Ocr`（取决于系统语言包）
- OCR 检测框为轴对齐矩形，竖排或明显倾斜文字效果有限；多栏版面不做分栏
- 随包运行时 + 模型使分发体积从 ~3 MB 增至 ~34 MB，首次识别有加载延迟
- 多显示器基于虚拟屏幕坐标，支持负坐标副屏
- 贴图只支持滚轮缩放，不提供边缘拖拽调整
- 配置修改后需重启生效
- 发布的 exe 未签名，分发到其他机器会遇到 SmartScreen 警告
