### 5.2 颜色面板悬停崩溃（已修复）

| 项 | 内容 |
|---|---|
| 现象 | 悬停/移动到颜色面板按钮后进程无提示退出，Windows 退出码 `-1073741819`（0xC0000005 访问冲突） |
| 根因 | 该按钮的快捷键改为空字符串后，`Tooltip::show` 把**空 `Vec<u16>` 的悬垂指针**与 `cchText = -1` 传给 `DrawTextW` 做宽度测量 → GDI 读取非法地址 |
| 触发链 | 悬停按钮 17 → `TIMER_TIP`(779) → `show_tip_for` → `Tip::show` → `measure(空 suffix)` → AV |
| 修复 | 空后缀跳过测量（`(sw, sh) = (0, 0)`），`tooltip.rs` 内注释说明原因 |
| 回归验证 | 复现脚本修复前稳定退出（0xC0000005），修复后同流程存活；features E2E 新增悬停按钮 17 用例并通过 |
